# Creating letters of the English alphabet using CSS.

## A personal project to test one's CSS skills.

This project is to test one's CSS skills by creating shapes using the following;

- ::before and ::after pseudo elements
- border and box-shadow
- relative and absolute positioning
- CSS transforms also.

The goal is to create the 26 unique capital letters of the English alphapet and then the small letters once the former has been completed. And through this process, expand one's reasoning of finding simplier and easier solutions to each letter shapes one encounters.
